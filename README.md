# visual-garman — интерактивный гайд по гармоническому анализу

Одностраничный визуальный гайд по курсу **«Гармонический анализ»** (МФТИ, ряды Фурье) в духе 3Blue1Brown: живые canvas-визуализации рядом со строгими формулировками и пошаговыми доказательствами.

Все пять блоков доступны: **20 пунктов программы**, 27 учебных разделов и 34 страницы доказательств/выводов.

- **1 · Ряды Фурье, билеты 1–7:** ядра, сходимость, Фейер, Вейерштрасс.
- **2 · Гильбертова теория, билеты 8–12:** нормы, проекции, Бессель, полнота, Рисс–Фишер.
- **3 · Интегралы с параметром, билеты 13–16:** собственные и несобственные интегралы, Коши, Вейерштрасс, Дирихле, Абель, перенос операций.
- **4 · Преобразование Фурье, билеты 17–19:** главное значение, симметричная нормировка, Дини, обращение, производные.
- **5 · Обобщённые функции, билет 20:** основные функции, сходимость в D и D′, дельта, производные и гладкие множители.

Новые интерактивы: общий контроль хвоста интеграла, гаусс/прямоугольник и спектр, действие приближений дельта-функции на компактный пробник. Добавлены единичные шары норм и пояснение символа Кронекера.

Строгие условия сверяются с `uploads/Конспект_лектора_Фурье_анализ_2024.md`; поясняющие примеры не выдаются за отдельные экзаменационные задания. В римановом обозначении RL₂ из конспекта не предполагается полнота лебегова L².

Стек: React 18 + KaTeX + in-browser Babel, графика на HTML canvas. Без шага сборки.

## Как открыть

- **Офлайн, без интернета:** двойной клик по [`гайд_оффлайн.html`](гайд_оффлайн.html) — единый файл, всё вшито (React/Babel/KaTeX + шрифты).
- **Локальный сервер (для разработки):** `python -m http.server 8000` в корне → <http://localhost:8000/>.
  Просто открыть `index.html` двойным кликом нельзя: in-browser Babel грузит `js/*.jsx` через XHR, который браузер блокирует на `file://`.

## Структура

| | |
|---|---|
| `index.html`, `js/`, `styles.css` | исходник (многофайловый, для сервера / GitHub Pages) |
| `гайд_оффлайн.html` | собранный офлайн-файл (двойной клик) |
| `_build_offline.py` | пересобрать офлайн-файл из `js/*` (`python _build_offline.py`) |
| `uploads/` | ТЗ и конспект — источники содержания |
| `_TODO_определения_и_блоки.md` | исторический список работ и текущий статус |

## Проверка

Установленный в рабочем окружении Python Playwright: `python check_guide.py http://127.0.0.1:8767/` при запущенном `python -m http.server 8767`. Проверяются формулы, все учебные и доказательные маршруты, интерактивы, мобильная ширина и офлайн-открытие без сети. После изменений: `python _build_offline.py`.
