# visual-garman — интерактивный гайд по гармоническому анализу

Одностраничный визуальный гайд по курсу **«Гармонический анализ»** (МФТИ, ряды Фурье) в духе 3Blue1Brown: живые canvas-визуализации рядом со строгими формулировками и пошаговыми доказательствами.

Блоки 1–2 проработаны полностью. **Блок 1 · Ряды Фурье** — §0 «до билетов» + Билеты 1–7 (лемма Римана, ядро Дирихле, признак Дини, порядок убывания, равномерная сходимость, Фейер, Вейерштрасс). **Блок 2 · Гильбертова теория** — §0 «до билетов» + Билеты 8–12 (минимальное свойство и неравенство Бесселя, полнота и равенство Парсеваля, Рисс–Фишер, полнота тригонометрической системы в L², полнота C[a,b]). Блоки 3–5 показаны как тизеры «coming soon».

Стек: React 18 + KaTeX + in-browser Babel, графика на HTML canvas. Без шага сборки.

## Как открыть

- **Офлайн, без интернета:** двойной клик по [`гайд_оффлайн.html`](гайд_оффлайн.html) — единый файл, всё вшито (React/Babel/KaTeX + шрифты).
- **Локальный сервер (для разработки):** `python -m http.server 8000` в корне → <http://localhost:8000/>.
  Просто открыть `index.html` двойным кликом нельзя: in-browser Babel грузит `js/*.jsx` через XHR, который браузер блокирует на `file://`.
